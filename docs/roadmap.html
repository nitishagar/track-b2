Roadmap

Where the project goes after the CLI core. Items are ordered roughly by planned sequence; nothing here changes the core promise — deterministic, offline, signoff-adjacent triage. For how the current pipeline works, see architecture.

WASM demo — shipped

Try it in your browser: the diff engine compiled to WebAssembly runs entirely on the page — drop two OpenSTA reports (or the sample pair) and get the clustered root-cause view in seconds. Files never leave the browser — the same offline guarantee as the CLI, packaged for evaluation without installing Rust. Output is byte-identical to the CLI's --format json, guarded by a CI parity check.

Exporter scripts

User-run, in-tool Tcl exporter scripts for PrimeTime and Tempus: source scripts the engineer runs in their own licensed session to dump paths/points as a JSON document (via documented get_timing_paths/report_timing-style commands) for otps to ingest. Shipped as source with no vendor binaries and no vendor sample outputs. Text-report parsers for commercial formats grow later, only from contributed, anonymized samples.

History store

Persist diffs across runs for trend analysis: per-run summaries in an embeddable store (DuckDB/Parquet, SQLite fallback — no server), multi-corner matrices, and trend charts answering "when did this endpoint group start drifting, and which component moved first?" Builds on the JSON output and the CI gate already shipped.

MCP server

An optional, off-by-default otps-mcp layer exposing the deterministic correlation engine to AI agents and local models (Ollama/vLLM). Positioning stays the same: the explainable correlation layer that agents — yours or the vendors' — can call, never an AI black box. Local-only, no telemetry, consistent with the air-gapped-farm constraint.

Also under consideration

  • Self-contained static HTML diff report (one shareable file, no server).
  • SPEF/Liberty-backed "why" drill-down: a library-diff module explaining part of a correlation delta.
  • SDF annotation-coverage check as a plugin.
  • Anonymizer-backed contribute flow for redacted sample sharing.
