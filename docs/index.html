otps — Timing-Correlation Diff Engine
Home Format Architecture Adopters Demo Roadmap

Path-level timing correlation across runs, corners, and flow revisions.

When slack for the "same" path differs between two analyses — pre- vs post-route, corner A vs B, flow v1 vs a ported v2 — otps aligns the paths and decomposes the delta per stage into cell delay, net delay, and a fully split required side (clocks, edge, uncertainty, CRPR, check margin, external delay). Miscorrelation triage starts from a ranked, attributed list instead of two text reports. Spec: OTPS format · pipeline: architecture · rollout: adopters.

What you get

  • Path matching with honest rates. Exact key (startpoint, endpoint, clocks, edges, group, check, flavor), then an inverted-index through-pin Jaccard fallback (≥ 0.5, same check) for renamed or ECO-touched paths. match rate counts exact pairs only; fuzzy pairs get their own fuzzy_rate / combined_rate, and unmatched paths are listed.
  • Stage-level attribution. Each matched pair is decomposed sign-aware over 11 components — cell/net per stage plus launch/capture clock, edge, uncertainty, CRPR, check margin, external delay — with derate and SI sub-splits, POCV sigma RSS, and a per-path confidence. The unexplained residual is always printed: a large residual means "uncertain", never "clean".
  • Root-cause clustering. Paths group by dominant component and path group (hierarchy prefix when ungrouped), so thousands of moved endpoints collapse to a handful of causes. Ordering is deterministic across runs.
  • CI-ready output. Human-readable summary or --format json; --fail-on-regression-ps N exits 2 when any matched path regresses more than N ps, or any added path violates beyond N ps absolute.

Fits your flow

  • Single static binary (cargo build --release); no root, no runtime, no installer. Runs on air-gapped farms.
  • Zero network calls and zero telemetry. --offline is the only mode; report files never leave the machine.
  • Reads real OpenSTA report_checks text or native STA JSON, plain or .gz, auto-sniffed; each side is labelled with its own run identity (--base-* / --new-*), and run mismatches print on every report.
  • Apache-2.0. No OpenSTA linking (GPL-3.0); public fixtures and demos use only OpenSTA/OpenROAD-style data.

Scope in v0.1.0 (schema 0.2.0)

InputsReal OpenSTA report_checks text, native STA JSON, legacy OTPS text v0.2; plain, .gz, or stdin
ChecksSetup/max and hold/min with per-check slack sign; clock segments, uncertainty, CRPR, check margin, external delay carried per path
OutputsText summary, JSON, exit codes 0 (ok) / 1 (error) / 2 (gate failed)
Not in scopeSignoff. This is signoff-adjacent triage: it narrows the suspect list, it never certifies timing

Accuracy basis

  • Self-consistency invariants checked per path (Σincrements = arrival, required − arrival = slack).
  • Perturbation-tested: injected net-delay growth and required-time shifts on the fixture pair are attributed to the right component at 100% explained.
  • 77 tests plus CI gates (build, clippy -D warnings, fmt --check, test, and an MSRV 1.85 build+test job) on every push, with sub-3x scale-ratio gates on ingest and fuzzy matching.

Quickstart

cargo build --locked
cargo run -q -p otps-cli -- diff fixtures/base.rpt fixtures/route.rpt --base-pdk sky130hd
cargo run -q -p otps-cli -- diff fixtures/base.rpt fixtures/route.rpt --fail-on-regression-ps 50

The first command builds the workspace. The second diffs the synthetic pre/post-route fixture pair. The third is the CI gate: it exits 2 because the worst matched regression (−102 ps) exceeds the 50 ps budget. Full flag reference is on the adopters page.

Try it in your browser

The live demo runs the real engine as WebAssembly: paste two reports and diff them locally, with an inlined sample pair to start from. After the page loads it makes zero network requests — your reports never leave the machine.
