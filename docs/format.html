OTPS text format v0.1

The Open Timing Path Schema (OTPS) text format is an OpenSTA report_checks subset mapping: one plain-text report holds any number of timing paths. Blank lines and lines starting with # are ignored. All delays are in nanoseconds. The CLI reads .rpt/.txt directly, plus .gz-compressed inputs; .json (or .json.gz) files are parsed as in-tool exporter JSON dumps instead (see parse stage).

Path block

Each path is a fixed-order header, a Points: line, one or more point lines, and a terminating End line:

Startpoint: <start pin/instance>
Endpoint: <end pin/instance>
Launch clock: <clock>
Capture clock: <clock>
Group: <path group, may be empty>
Check: setup|max|hold|min
Slack: <ns>
Required: <ns>
Arrival: <ns>
Crpr: <ns>
Uncertainty: <ns>
Points:
<point line>
...
End

Point line

Point lines use pipe-separated columns followed by space-separated key=value attributes:

<pin> | <cell type> | <net> | cell=<ns> net=<ns> slew=<ns> cap=<pf> fanout=<int> [derate=<mult>] [sigma=<ns>] [si=<ns>]
AttributeMeaningRequired?
cellCell (gate) incremental delay, nsNo (default 0)
netNet (wire) incremental delay, nsNo (default 0)
slewTransition slew, nsNo
capLoad capacitanceNo
fanoutFanout count (integer)No
derateApplied derate multiplierOptional
sigmaPOCV/LVF sigma, nsOptional
siSI-induced delta delay, nsOptional

Only the pin column is required; cell/net columns may be empty. Unknown attribute keys are a parse error (reported with a 1-based line number).

Example

# Pre-route path on sky130hd (synthetic OpenSTA-style data).
Startpoint: u_core/ff1
Endpoint: u_core/ff2
Launch clock: clk
Capture clock: clk
Group: clk
Check: setup
Slack: 0.100
Required: 1.000
Arrival: 0.900
Crpr: 0.000
Uncertainty: 0.050
Points:
u_core/ff1/CK | DFFHQX1 | net_clk1 | cell=0.050 net=0.010 slew=0.020 cap=0.003 fanout=2
u_core/ff2/D | DFFHQX1 | net_d1 | cell=0.640 net=0.200 slew=0.040 cap=0.005 fanout=1 derate=1.050
End

Self-consistency invariants

Every path must satisfy (within 1e-6 ns, checked by diff before matching):

  • sum(point cell + net increments) == arrival
  • required - arrival == slack

A violation is reported as an error naming the endpoint — it flags a parser or exporter bug, never a timing verdict.
